# Air Survey — install files

Public download home for the **Air Survey** tablet app (aerial ungulate survey data collector for park wildlife surveys). The code and documentation live in a separate private repository; this one exists only so crew members can always reach the latest installable build — no account needed.

## Install on a tablet

1. Download the newest `.apk` from **[Releases](https://github.com/gitJMDR/airsurvey-releases/releases)**.
2. Open the file on the tablet and allow "install unknown apps" if asked.
3. **Updating an existing install?** Install right on top of the old version — **never uninstall first**: uninstalling erases any recorded survey data that hasn't been exported yet.
4. **New tablet?** After installing, download the offline maps once while on Wi-Fi: open the app → **⚙ SETUP → OFFLINE MAPS → Download** (satellite ~170 MB, road map ~40 MB). After that the map works with no connection at all.

Questions or something broken: see the project's USER-GUIDE, or ask Jonathan.
